🔔 Bildirim Gönder

Bildirimler Firebase Console üzerinden gönderilir: Console → Messaging (Engage) → New campaign → Firebase Notification messages.

  1. Herkese: Hedef olarak User segment → Web uygulaması’nı seç (Cloud Function gerekmez).
  2. İl / üniversiteye özel: functions/ klasöründeki fonksiyonu deploy ettiysen hedef olarak Topic seç ve aşağıda oluşan topic adını yapıştır.
  3. Bildirime tıklayınca belirli bir sayfa açılsın istersen “Additional options → Custom data” kısmına link = / gibi bir değer ekleyebilirsin.
